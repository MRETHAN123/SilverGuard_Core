# 续费分析器（SilverGuard）

本项目主要面向需要帮助辨别续费通知和账单信息的用户，尤其是部分不熟悉数字服务的老年用户。SilverGuard 可以分析用户输入的续费短信或账单文字，提取服务名称、金额及续费相关信息，并给出相应的核实建议。同时，项目能够根据部分可疑文本提示潜在风险，帮助用户提高警惕，降低受骗风险。

本项目目前仅提供核心功能骨架。后续可根据实际需要扩展图片识别、辅助触控、通知家人等高级功能。

## 文件结构

- `main.py`：运行入口，接收账单输入，打印分析结果；输入 `summary` 查看本次账单汇总
- `config.py`：**全部 Agent 设置都在这里直接修改**，包括是否启用、模型地址、模型 ID、API Key、Prompt
- `silverguard/core.py`：账单分析、风险规则、解释和建议


## 注意：

1. 为项目选择 Python 3.10+ 解释器（推荐 3.11）。
2. 在项目根目录的终端执行：

```powershell
python main.py
```

输入示例：

```text
支付宝 腾讯视频VIP 连续包月 ￥25
```

再次输入另一笔账单可继续分析；输入 `summary` 查看本次汇总，输入 `q` 结束。

## 配置 Agent

打开 `config.py`：

```python
ENABLE_AGENT = True
LLM_BASE_URL = "api地址"
LLM_MODEL = "你实际可以调用的模型ID"
LLM_API_KEY = "你的密钥"
```

然后**直接运行 `python main.py`**。不需要 `--llm` 参数，更不需要在网页上勾选任何设置。若使用本机 Ollama 的兼容接口，可以把 `LLM_BASE_URL` 改成 `http://127.0.0.1:11434/v1`，`LLM_MODEL` 改成已经拉取的模型名，本地接口通常不需要 API Key。

## 目前 Agent 能做什么？
Agent 会将**原始账单文字**和本地规则分析摘要发送给模型。模型可以尝试：

- 识别规则词典中没有的服务名称；
- 推断服务类别，包括词典中没有的新类别；
- 补充服务含义、账单文字解释、风险提示和下一步建议；
- 在原文有明确证据时，辅助提取规则未识别的金额或续费状态。

程序会保留本地规则已经明确识别的服务、类别和金额；模型补充的新服务名称应能在输入文字中找到对应片段，金额和续费状态也会进行原文证据检查，但这些检查不能保证完全正确。模型无法确定时应返回“待确认”，不能凭空创造商户或声称已查验真实账户。

**它还不是自由对话或自主工具调用 Agent。** 本版本保留了现有核心能力，没有额外接入 OCR、账户访问或自动取消订阅等功能。
